# MarkItDown Document Extraction Skill

Use this skill whenever working with complex or binary documents (PDFs, Word, Excel, PowerPoint, ZIP files, HTML pages) to extract and convert their contents to Markdown.

## Usage Guidelines
1. Use for large, raw, or binary files that are not yet visible in context.
2. Skip if the file content is already visible in context to save time and token limits.

## Supported Formats
* PDF documents (.pdf)
* Microsoft Word (.docx)
* Microsoft Excel (.xlsx, .xls)
* Microsoft PowerPoint (.pptx)
* HTML pages and web archives
* ZIP archives containing documents
