# Truth Prompt Skill

A shared agent skill that disciplines AI outputs to separate verified facts from inferences, assumptions, and guesswork before answering.

## Overview
`truth-prompt` ensures AI responses avoid false confidence. It enforces open communication regarding confidence levels (**High / Medium / Low**) and highlights unverified assumptions or missing data.

## Features
- **4-Bin Fact Sorting**: Verified Facts, Reasonable Inferences, Working Assumptions, and Unknowns.
- **Plain-Language Confidence**: High / Medium / Low ratings with concise justification.
- **Zero Fabrication**: Strictly prohibits inventing stats, sources, or quotes to fill gaps.
- **Structured Output**: Clear breakdown of Answer, Confidence, Dependencies, and Unverified/Missing items.
